# Bump in the Dark (Revised Edition) — PDF Page Index

Reference file for `Bump in the Dark Revised Edition V1.01 - LoRes.pdf`, found at
`C:\Users\macar\.claude\reference\Bump in the dark\`. Use page numbers here to find
sections without re-reading the full 159-page document. A Forged in the Dark game
